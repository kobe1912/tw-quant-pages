## 3. 共用定義（工程設計）

- 預設日線收盤掃描，僅處理完整K棒。t為最新完整棒；O/H/L/C/V為開高低收量。
- MA(n,t)=截至t之n根收盤簡單平均；ATR14採Wilder平滑，種子為最初14根TR均值，TR=max(H-L,abs(H-C前根),abs(L-C前根))。
- PH(n,t)=max(H[t-n:t-1])；PL(n,t)=min(L[t-n:t-1])；AV20(t)=mean(V[t-20:t-1])；相對量RV=V[t]/AV20(t)。分母0、暖機不足即DATA_MISSING。
- 上升U：MA20>MA60，且MA20[t]>MA20[t-5]；下降D反向。盤整R：abs(MA20[t]/MA20[t-5]-1)<=1%，且PH20/PL20-1<=12%。皆未符合為轉換中。先判U/D，再判R；這些分類須以樣本外結果調整。
- 糾結W=(max(MA5,MA10,MA20)-min(...))/C；壓縮：前5棒至少3棒W<=1.5%；發散：W[t]>W[t-1]且MA5>MA10>MA20，三線均較前根上升。
- 回測站穩touch(S)：L<=S+0.3*ATR，L>=S-0.5*ATR，C>S，C>O。S只取當下已知支撐。
- 上破cross(S)：C[t]>S[t]+0.1*ATR[t]，且C[t-1]<=S[t-1]+0.1*ATR[t-1]。動態線需分別使用兩根當時線值；固定價位則兩值相同。
- Pivot以左右各2根辨識，低點為5根最低、高點為5根最高；同價只保留最早者。位於i的pivot到i+2收盤才可使用。所有斜線及型態只能使用已確認pivot；候選成立即凍結型態端點，禁止事後重畫舊訊號。
- 近60棒的已確認pivot作型態候選，轉折須交替，高低間距至少3棒；同一型態只取最近符合的一組。頂／底相近容許差為max(價格3%,ATR14)。
- 止損距離、預期報酬與部位大小均以實際成交價重新計算。日線訊號預設下一交易日開盤撮合；開盤追價超過訊號收盤0.5ATR或初始風險超過成交價8%則跳過（研究門檻）。
- 結構停損均加減一個合法跳動單位。交易成本、稅率、tick依產品與生效日期設定，未配置時不得發布淨績效。

## 7. 狀態、欄位與網站呈現

狀態：WATCH（結構候選）、CONFIRMED（完整K棒確認）、TRIGGERED（指定價格已觸發，非成交）、FILLED（只有券商或明確模擬成交記錄）、INVALIDATED（結構失效）、EXPIRED（超時）、DATA_MISSING（資料不足）、CONFLICT（多空衝突）。

日收盤市場單計畫：t確認→t+1開盤檢查追價和風險→符合才模擬成交；TRIGGERED不能在前端被翻成已成交。盤中未完成棒僅顯示PREVIEW且不能進入正式績效。次日未成交不延用昨日進場價；預設有效1交易日。

## 8. 資料需求與部署方式

- P2盤中：至少60分與5分完整K棒，能取得才啟用DEN03/07/08；只有日線不能冒稱盤中訊號。大週期必須取小週期觸發當刻已完成者，不能讀到該日最終日K。
- 回測股票池需涵蓋下市與歷史可交易名單，避免存活偏誤。短方需借券／期貨可交易性、成本與限制，不預設所有現股可放空。
- GitHub Pages顯示預先產生的JSON；日線工作流在收盤資料完整後執行。此規格沒有讀取現有網站程式、沒有建立或更動Actions，也沒有部署。
- pipeline：load_data → validate → compute_features → detect_setups → confirm_signals → deduplicate → apply_execution_gates → emit_json → backtest/forward_log。
- 機密金鑰僅放後端／Actions secrets，不能進公開JSON。

## 9. 統一風控與驗證門檻

研究預設：每筆最大帳戶風險0.5%，全部持倉初始風險合計<=3%，單股資金占比<=10%；計算股數=floor(min(權益*0.5%/每股風險,權益*10%/成交價))，另扣成本緩衝並按交易單位取整。帳戶權益未知時只提供每股風險，不自造股數。

趨勢類預設2R減半、餘額收盤跌破MA10下一開盤出；箱型以箱頂附近出；反彈類最多5棒或MA10失守出。初始硬停損持續有效；不得下移多單停損。減半須考量最小交易單位，無法分割則全出。加碼預設停用，獨立回測後再開。

硬停損：開盤低於停損以開盤加滑價成交；日內觸及以停損加滑價估計，跌停無法成交則延後並揭露。日棒同時碰停損與目標時採保守停損先行，或使用更細資料確認。

驗證：按時間切分訓練、驗證、樣本外，持倉跨切點須隔離，門檻選擇只用訓練；逐策略、族群、市場狀態分報交易數、淨期望R、PF、MDD、曝險時間、換手與區間估計。交易樣本太少標INSUFFICIENT_SAMPLE，不排名。

必要工程檢查：任意日期截斷後訊號不可改變；大週期未完成不能被引用；除權息不產生假突破；缺資料不產生BUY；同型態不重複下單；停損跳空與雙碰按既定規則；輸出完整資料日期；模擬持倉與實際成交分開。

## 11. 六策略正式基準：共用契約

本節以後是根據教材概念自行設計的研究系統，不是教材原文規則。先固定參數建立baseline，之後才能比較改動，禁止依歷史圖逐檔挑均線。

### 11.1 股票池與資料

- 市場：台灣上市、上櫃普通股；基準版排除ETF、權證、特別股、興櫃與非股票產品。使用歷史當時存在的股票池。
- 以個股交易日為棒序號；至少250根完整有效日K，最近20個市場交易日均須有有效行情，停牌或缺棒不以0補值。
- 前20日原始成交金額均值>=新台幣5,000萬元，訊號日有成交；此數字為容量研究門檻，不是教材門檻。交易狀態未知時只輸出觀察。
- 指標與型態使用一致的還原價格；每日保留當時資料快照，除權息因子更新不得改寫既存訊號。成交使用原始價格，對支撐、目標、停損作同基準轉換。事件無法轉換或停損單位不明時禁止模擬下單。
- 不要求所有策略都通過V3.3>=65、法人或財報條件。這些是獨立實驗的可選模組，不影響baseline。
- 大盤與族群在baseline只顯示標籤，不作硬濾網。缺少族群不阻止純價格策略；缺少個股必要資料則阻止。

### 11.2 計算及時序

- PHn(t)、PLn(t)、AV20(t)皆只用t前n根，不含t。比較基準固定以訊號前可得資料建立。
- U(t)：MA20(t)>MA60(t)且MA20(t)>MA20(t-5)；D(t)完全反向。
- ATR採第3節Wilder算法。日K零振幅不參與影線訊號；缺量、負價或AV20=0回報DATA_MISSING。
- 所有trigger於t完整收盤判斷；日線不宣稱收盤前可提前知道最終訊號。確認後僅於t+1開盤模擬成交，不能回填t收盤價。
- 候選須記錄anchor_time、anchor_price、confirmed_at、expires_at。候選失效後不事後復活；重新成立使用新setup_id。
- t+1若停牌、開盤無法成交、觸及預定退出條件或超過追價範圍則取消；不順延找更好價位。停損後至少冷卻5交易日，且必須新setup才能重進。
- E=原始開盤價加不利滑價後成交價（空方減不利滑價）；S=原始初始停損；R=abs(E-S)，成交後固定，不隨移動停損重算。
- 單檔風險距離R/E必須介於0.5%與8%；不合格則跳過，不將停損硬改到門檻內。
- 多方成交須E>S，空方E<S。開盤已越過目標或預定退出門檻則取消。
- 多單E不得高於訊號收盤+0.5ATR(t)；空單E不得低於訊號收盤-0.5ATR(t)。價格、ATR皆轉為同原始基準。
- 本規格使用市場單入場與收盤決策出場，不使用會產生撮合順序疑義的盤中獲利限價單。硬停損為唯一預設盤中退出單。

### 11.3 部位與執行

- S1/S2/S3/S4每筆帳戶風險上限0.5%；S5/S6為0.25%。全帳戶按現有有效停損估算風險總和<=3%；多方單股名目資金<=10%、同族群<=25%，最多10檔。族群未知時該檔占用獨立unknown群組，共享25%上限。
- 預設不借款；總多單名目資金<=帳戶權益。空方研究另分帳戶，名目曝險<=權益，不與多方做虛擬抵銷降低保證金。未建保證金模型不支援期貨成交模擬。
- 多單股數按風險上限、個股占比、可用資金、族群限額及成交容量取最小值；成交容量<=前20日平均成交股數0.1%，另以成本緩衝修正。最小交易單位由市場與交易方式設定，不能假設一律1000股。
- 空方另檢查借券可得、有效數量與借券成本，未具備者為SHORT_WATCH，不納入可執行淨績效。持股者可顯示減碼警示，但不能自動假設他持有股票。
- 加碼全部預設關閉。策略完成驗證後另立ADD版本，不能在回測中途人工加碼。
- 成本設定必須包含生效日期、買賣手續費、交易稅、滑價及空方每日借券費。費率由執行環境驗證配置，本規格不填可能過時的法定稅率。

## 14. S3 反轉確認：W底頸線突破

## 16. S5 提前反轉：假跌破收復

ID=S5_FAILED_BREAKDOWN；family=early_reversal；direction=long；映射DEN06，一般化假跌破，不宣稱擴張型已成立。DT12長下影為可選標籤，非必備。

ID=S6_DOUBLE_TOP_EARLY_SHORT；family=short_reversal；direction=short；映射DT18。此基準保留提前放空概念，並非頸線跌破確認版。

## 18. 統一退出、衝突與前端契約（取代v1含糊處）

- 優先順序：不可交易或資料缺失→既有硬停損→已排定全出→已排定減碼→新進場。所有全出優先於減碼。
- 硬停損盤中優先；停利、均線、型態失敗及時間出場皆由當根收盤決定並於次開盤執行。禁止以收盤才知道的決策回填當日盤中成交。
- 移動停損須用前一完整交易日資訊，當日收盤更新後自次交易日生效。未成交減碼的餘額保護規則亦於下一日預先生效；實際開盤先觸停損則全出，不再減半。
- 已持倉出場後不於同開盤反手或重進。未成交、取消、資料不足均不算交易，不納入勝率分母。
- 持有棒數從成交當日記1；第N棒收盤觸發時間退出，於下一開盤執行，故最長暴露會多一個開盤間隔，報表需呈現實際時間。
- 達2R或型態目標是收盤決策，不保證實際成交獲利達該數字；開盤跳空可能降低獲利甚至轉虧。
- 一筆只有一個family歸屬。突破當下DT16歸S2、其後回測歸S1；一般假跌破歸S5而非S3。同時命中多個long基準按S1→S2→S3→S4→S5固定順序選primary，其他保留secondary，不能看事後績效挑。
- 原始訊號全保留供逐策略研究；單策略回測各自獨立；合併投組回測用上述primary優先與一股一倉。兩者報表分開，避免重複計算投組損益。
- 同股票同時有long與short為CONFLICT，禁止新部位；既有部位仍依自己的退出規則，不憑衝突直接反手。
- 只顯示一次首次CONFIRMED時間；後續每日持有狀態不重報新BUY。WATCH預設10棒過期，S3/S5按各自專屬時間。
- 建議前端欄位：strategy_id、strategy_version、family、direction、action、status、setup_id、anchor_time、confirmed_at、valid_until、data_asof、entry_plan、stop_price、target_price、estimated_rr、risk_pct、high_risk、data_quality、execution_eligibility、primary、matched_rules、exit_reason、backtest_status。
- 補正v1：未知停損的JSON只可status=WATCH或SCHEMA_EXAMPLE；正式CONFIRMED不得stop_price=null。預期價格範圍與RR以最新已知值計，實際成交再驗證；estimated_rr不是保證報酬比。

## 19. 驗收與發布準則

規格完成≠策略實作完成≠回測通過≠已上線。全部六策略初始backtest_status=UNVALIDATED。缺盤中來源時日線策略仍可研究，DEN03等維持disabled。

工程測試至少涵蓋：
1. 正例／反例與每個門檻邊界；S3/S6的pivot確定時間；S5 g+2最早成交。
2. 資料任意截斷後舊訊號不改變；除權息轉價一致；大週期不偷看未完成棒。
3. 下一開盤追價取消、開盤越停損、停牌、漲跌停鎖單、借券召回、減碼不足最小單位。
4. 共用候選去重、六策略primary歸屬、多空衝突與一股一倉、缺失資料不能產生正式成交。
5. 移動停損僅次日生效；部分減碼後股數、成本與現金一致；退出原因可重現。

研究報告至少逐策略呈現：歷史期間、樣本數、年別及市場狀態、成本前後期望R、勝率、平均盈虧比、PF、最大回撤、曝險時間、最長連虧、參數鄰域穩定性與成本加倍壓力測試。策略樣本外交易少於50筆標INSUFFICIENT_SAMPLE，此門檻只為報告警示，不代表50筆足以證明有效。

以時間先後切分訓練／驗證／保留樣本外，切點隔離最大持倉期間，禁止先看保留段再調參。觀察名單在公開頁可標研究訊號；只有程式測試、資料與成本檢查完成才可啟用正式掃描，是否值得交易仍須依樣本外及前瞻結果判斷。

交付狀態：六個baseline規格已明確；未寫策略程式、未取得行情回測、未執行投組模擬、未部署網頁。後續開發以本版本strategy_version=research-v2固定起始參數。
